# 简介

HeroUI Vue 是一个现代、可访问的 Vue 3 组件库，基于 Tailwind CSS 构建。它提供了一套完整的 UI 组件，易于使用、定制，并可轻松集成到你的 Vue 应用中。

## 特性

- **Vue 3 Composition API**：基于 Vue 3 与 Composition API 从零构建
- **可访问性**：基于 Radix Vue primitives 构建，确保符合 WCAG 标准
- **可定制**：使用 Tailwind CSS 编写样式，主题定制简单
- **TypeScript**：完整的 TypeScript 支持，附带全面的类型定义
- **暗色模式**：内置暗色模式支持
- **Tree-shakeable**：按需引入，只打包你使用的组件

## 设计理念

HeroUI Vue 遵循以下核心原则：

1. **可访问性优先**：每个组件在设计时都以可访问性为先
2. **开发者体验**：简单直观的 API，易于学习和使用
3. **可定制**：灵活的样式系统，适配你的设计需求
4. **性能**：针对速度与最小包体积做了优化
