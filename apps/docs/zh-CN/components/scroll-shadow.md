# Scroll Shadow 滚动阴影

带边缘阴影的可滚动区域。

## 导入

```ts
import { ScrollShadow } from '@misaki-mei/heroui-vue'
```

:::preview

demo-preview=../../demos/scroll-shadow-basic.vue

:::

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` | 滚动方向 |
| `size` | `number` | `40` | 阴影尺寸 |
| `visibility` | `'auto' \| 'both' \| 'top' \| 'bottom' \| 'left' \| 'right' \| 'none'` | `'auto'` | 受控的可见性 |
