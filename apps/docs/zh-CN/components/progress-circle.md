# Progress Circle 环形进度

环形进度指示器。

## 导入

```ts
import { ProgressCircle } from '@misaki-mei/heroui-vue'
```

demo-preview=../../demos/progress-circle-basic.vue

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `value` | `number \| undefined` | `undefined` | 当前值；省略则为不确定状态 |
| `color` | `'default' \| 'accent' \| 'success' \| 'warning' \| 'danger'` | `'accent'` | 描边颜色 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 圆环尺寸 |
