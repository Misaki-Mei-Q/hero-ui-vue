# Tag 标签

可选择或可移除的标签。

## 导入

```ts
import { Tag, TagGroup, TagRemoveButton } from '@misaki-mei/heroui-vue'
```

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `selected` | `boolean` | `false` | 将标签标记为选中状态 |
| `variant` | `'default' \| 'surface'` | `'default'` | 视觉样式 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标签尺寸 |
