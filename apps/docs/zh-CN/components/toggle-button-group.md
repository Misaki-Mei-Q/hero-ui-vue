# Toggle Button Group 切换按钮组

相关切换按钮的布局包装器。

## 导入

```ts
import { ToggleButtonGroup, ToggleButtonGroupSeparator } from '@misaki-mei/heroui-vue'
```

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 布局方向 |
| `isDetached` | `boolean` | `false` | 渲染为彼此分离的按钮 |
| `fullWidth` | `boolean` | `false` | 填满父容器宽度 |
