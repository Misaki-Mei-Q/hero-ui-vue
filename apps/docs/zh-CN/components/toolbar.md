# Toolbar 工具栏

承载相关操作的工具栏容器。

## 导入

```ts
import { Toolbar } from '@misaki-mei/heroui-vue'
```

demo-preview=../../demos/toolbar-basic.vue

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 工具栏方向 |
| `isAttached` | `boolean` | `false` | 相连的视觉样式 |
