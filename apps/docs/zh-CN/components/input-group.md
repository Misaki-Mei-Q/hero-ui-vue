# Input Group 输入组

带有前缀、后缀和 textarea 插槽的输入框外壳。

## 导入

```ts
import {
  InputGroup,
  InputGroupInput,
  InputGroupPrefix,
  InputGroupSuffix,
  InputGroupTextArea,
} from '@misaki-mei/heroui-vue'
```

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `variant` | `'primary' \| 'secondary'` | `undefined` | 视觉样式 |
| `fullWidth` | `boolean` | `false` | 填满父容器宽度 |
