# Tabs 标签页

标签式内容导航。

## 导入

```ts
import { Tab, TabList, TabPanel, Tabs } from '@misaki-mei/heroui-vue'
```

demo-preview=../../demos/tabs-basic.vue

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `value` | `string` | `undefined` | 受控的选中标签页 |
| `defaultValue` | `string` | `undefined` | 初始选中的标签页 |
| `variant` | `'primary' \| 'secondary'` | `'primary'` | 视觉样式 |
