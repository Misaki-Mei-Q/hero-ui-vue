# Toggle Button 切换按钮

可按下的切换控件。

## 导入

```ts
import { ToggleButton } from '@misaki-mei/heroui-vue'
```

demo-preview=../../demos/toggle-button-basic.vue

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `selected` | `boolean` | `undefined` | 受控的选中状态 |
| `defaultSelected` | `boolean` | `false` | 初始选中状态 |
| `variant` | `'default' \| 'ghost'` | `'default'` | 视觉样式 |
