# Fieldset 字段集

带有标题说明、分组字段和操作按钮的表单区块布局。

## 导入

```ts
import { FieldGroup, Fieldset, FieldsetActions, FieldsetLegend } from '@misaki-mei/heroui-vue'
```

## API

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `disabled` | `boolean` | `undefined` | 禁用原生 fieldset |
