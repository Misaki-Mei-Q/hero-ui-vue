# Toggle Button Group

Layout wrapper for related toggle buttons.

## Import

```ts
import { ToggleButtonGroup, ToggleButtonGroupSeparator } from '@misaki-mei-q/heroui-vue'
```

demo-preview=../demos/toggle-button-group-basic.vue

:::

## API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout orientation |
| `isDetached` | `boolean` | `false` | Render separated buttons |
| `fullWidth` | `boolean` | `false` | Fill parent width |
