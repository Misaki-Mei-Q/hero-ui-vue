# Toolbar

Toolbar container for related actions.

## Import

```ts
import { Toolbar } from '@misaki-mei-q/heroui-vue'
```

demo-preview=../demos/toolbar-basic.vue

## API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Toolbar orientation |
| `isAttached` | `boolean` | `false` | Attached visual style |
