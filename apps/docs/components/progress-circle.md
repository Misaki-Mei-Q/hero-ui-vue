# Progress Circle

Circular progress indicator.

## Import

```ts
import { ProgressCircle } from '@misaki-mei-q/heroui-vue'
```

demo-preview=../demos/progress-circle-basic.vue

## API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number \| undefined` | `undefined` | Current value; omit for indeterminate state |
| `color` | `'default' \| 'accent' \| 'success' \| 'warning' \| 'danger'` | `'accent'` | Stroke color |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Circle size |
