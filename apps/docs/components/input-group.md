# Input Group

Input shell with prefix, suffix, and textarea slots.

## Import

```ts
import {
  InputGroup,
  InputGroupInput,
  InputGroupPrefix,
  InputGroupSuffix,
  InputGroupTextArea,
} from '@misaki-mei/heroui-vue'
```

## API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'primary' \| 'secondary'` | `undefined` | Visual style |
| `fullWidth` | `boolean` | `false` | Fill parent width |
